Install Star Hub

  1. Run the setup on Windows 10 22H2 (build 19045) or Windows 11. Setup includes the required runtimes and opens Star Hub when it finishes.
  2. Sign in to use your saved OpenAI connection. Turn on Long-term memory to share notes with the web.
  3. To try a workbook lesson, say “teach me manufacturing costing” with Operate this PC enabled, or choose Learn with this workbook on a cost workbook you created.

To update, finish active tasks, close Star Hub, and run the new setup. Your local data is kept. If already signed in, select your name and choose Refresh from website once to connect account memory.

Use Qwen for offline chat

Install Ollama for Windows. While online, run this command once in PowerShell. Keep Ollama running and leave Star Hub’s model set to Automatic.

ollama pull qwen2.5:0.5b

The installer is unsigned. Windows SmartScreen may show a publisher warning. Verify the file against the published SHA-256 checksum.
