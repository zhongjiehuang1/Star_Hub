Install Star Hub

  1. Open the downloaded setup file on a 64-bit PC running Windows 10 version 22H2 (build 19045) or Windows 11. Setup includes the required runtimes and opens Star Hub when it finishes.
  2. In Settings, add your OpenAI key, choose an installed Ollama model or connect a compatible API.

Updating an existing installation? Finish active tasks, close Star Hub and run the new setup. Your local data is kept.

The installer is unsigned. Windows SmartScreen may show a publisher warning. Verify the download against the published SHA-256 checksum.
