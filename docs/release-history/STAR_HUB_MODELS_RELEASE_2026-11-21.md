Both application servers run the same reviewed Star Hub WAR, SHA-256 `e6442730c9c448ce79b1012cd8d09905f71b6d959662da94519c2bac099ddbf7`. Release ID: `c72452f7-507e-45cd-b2d0-f3ddd6d209c0`.
