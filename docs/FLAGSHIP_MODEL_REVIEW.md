# Current model selection

The catalogue identifies a flagship and, where independently documented and integrated, an alternative for each provider and creation direction. The alternative is the default for a new selection; an existing usable user choice is retained. Neither label promises that an alternative is cheaper or faster for every account or task. DeepSeek has one verified current selection; additional models and video creation are not invented where an integration is unavailable.

OpenAI defaults to GPT-6.1 Sol for chat, GPT Image 2.6 Flare for image work and GPT Realtime 2.1 Mini for live voice. The previously integrated transcription and batch capabilities remain available. The user-facing picker omits embeddings, while the backend keeps its existing historical embedding and batch compatibility paths.

Provider documentation links are recorded with each model. Local tests use stubs and do not prove paid provider availability, account entitlements, regional access or current production behavior. Official prices and limits may change. The xAI Voice API is an existing service integration, not a fabricated language-model identifier.

`research/official-models.json` is the reviewed editable source; `scripts/build-catalog.py` generates the runtime catalogue. Neither file should contain credentials or user data.
