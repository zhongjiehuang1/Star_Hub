# Rendering model answers

The interface renders Markdown headings, emphasis, lists, tables, quotations and code blocks, including in the optional reasoning summary. Mathematical expressions written using `\(...\)`, `\[...\]`, `$...$` or `$$...$$` are rendered locally with KaTeX 0.19.1 and its bundled WOFF2 fonts. Long equations and tables can scroll on small screens. Actual code blocks remain selectable text and are not interpreted as formulas. Unsupported or invalid mathematical expressions can fall back to visible source instead of silently changing their meaning.

Model output is untrusted: Markdown is sanitized before it is added to the document. KaTeX renders only recognized formula tokens with trusted HTML commands disabled and bounded expansion; raw HTML images and scripts are removed. Up to twelve Markdown images in a completed answer can be displayed from HTTPS hostnames; address literals, credentials and non-default ports are rejected. The browser loads these images anonymously without a referrer, so the image host can still see the viewer's IP address, and the host must permit cross-origin image loading. A failed image leaves a link to the original. Images are not loaded during the streaming reveal or from reasoning summaries. The original answer remains unchanged in stored conversations. The local vendor distribution was checked against the npm registry SHA-512 and includes its license. This browser-only presentation change does not alter provider requests, account identity, stored chat data or database operations.

Release verification included a local real-browser matrix and table example, preserved fenced code, HTML/script injection and unsafe-link checks, existing JavaScript and Java tests, and a live historical matrix conversation. The personal portfolio release filters UCost from public presentation while preserving the source test evidence, identifies the public certificate as the bachelor's certificate, and uses award dates for both degrees.
